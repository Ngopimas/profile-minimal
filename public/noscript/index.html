NOSCRIPT A zine in six documents · November 2026

Nothing on this page is JavaScript.

NOSCRIPT is a small zine. It has sheets that stack in three dimensions, a drum that turns as you read, a combination lock, menus that climb out of the boxes that clip them, and pages that turn. It has no script element, no canvas and no event handler.

Each of its five pages is about one job the web used to hand to JavaScript, and each page does that job in front of you without it. The code that retired is printed next to the code that replaced it. Where your browser cannot run a specimen yet, the page says so and shows you the plain version instead, and it knows which is which without asking a script.

This is the mirror of the three earlier rendering experiments on this site. LUMEN and MATERIAL are each a shader behind a scrolling essay, QUARTO draws its HTML into a canvas, and none of them could exist without code. I wanted to know how far the document gets by itself at the end of 2026. Further than I expected, and not as far as the demos suggest. Both halves are in here.

What this cannot do

A claim like the one in the title deserves its own list of exceptions.

  • It cannot remember. State lives in form controls and in the URL. Turn the page and the lock on page 02 forgets what you dialled.
  • It cannot read a value. CSS can tell that a box is checked. It cannot see the number on a range slider or the text in a field, so there is no slider anywhere in this zine.
  • It cannot talk to a server. No fetching, no saving. Links and forms are still the only requests a document can make.
  • It cannot detect its own best trick. There is no @supports test for cross-document view transitions, which is why the table above shrugs at them.
  • It cannot load the next page early. Speculation rules are JSON inside a script element. That is still a script element.
  • And some of it should not be copied. A lock made of thirty radio buttons is a specimen. The accordion, the popovers and the page transitions are how I would build those things today.

Proof. Script elements in this document: 0. Canvas elements: 0. Event handler attributes: 0. The stylesheet checks the first number with :root:has(script) and strikes it out if it is ever wrong. This page also carries a Content-Security-Policy of script-src 'none', so your browser would refuse to run a script even if one were here.

Do not take the page's word for it. View the source (Ctrl U, or ⌘ ⌥ U) and search for “<script”, or switch JavaScript off and reload: nothing will change. Everything that moves is in one unminified stylesheet.
